## DHAKIR An AI integrated Quran Application.
##### 'Dhakir' 'ذاكر' means the one who constantly remembers Almighty God.
## Tech Stack & Tools

### Frontend
- **ReactJS** (with JavaScript)
- **Vite** (Build tool)
- **Tailwind CSS** (Styling)
- **React Icons** (Icons)
- **Flutter**

### Backend & Infrastructure
- **Python & FastAPI** (Backend framework)
- **Vercel Serverless** (Backend hosting, migrated from serverful Render.com)
- **Cloudflare Pages** (Frontend hosting)
- **Upstash Redis** (Caching and session management)

### APIs
- **Quran Foundation Content APIs** (Verses, Chapters, Info)
- **Quran Foundation User APIs** (Profiles, Bookmarks, Reading Sessions, Activity Days, Streaks)
- **Quran Foundation OAuth2** (Authentication)

### Design & Utilities
- **Glyphs App** (Inspecting Uthmani Script unicodes)
- **Affinity Designer 2** (Logo creation)
- **Microsoft PowerPoint**
- **Adobe Premiere Pro** (Demo video creation)
